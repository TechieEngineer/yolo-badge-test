# 🏅 GitHub Badges Guide

This repository is a step-by-step guide to help you unlock GitHub achievements!

## 🚀 How to get the YOLO Badge
1. Create a public repository with a README.
2. Edit the README, but select **"Create a new branch"** instead of committing to main.
3. Open a Pull Request.
4. Merge the Pull Request yourself without any code reviews!
